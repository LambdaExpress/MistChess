# MistChess audio assets

`mistchess-tone.ogg` and `mistchess-tone.mp3` are original procedural tones
generated for this project with FFmpeg's sine source. They contain no
third-party recordings and are distributed under the same license as MistChess.

Both encodings contain the same 120 ms source tone. The client changes playback
rate per safe game event so one maintained asset covers all UI sounds.
