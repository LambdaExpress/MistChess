# MistChess audio assets

`move.ogg` and `move.mp3` are original procedural recordings generated for
MistChess from deterministic filtered-noise and resonant wood-impact synthesis.
They contain the same 145 ms source sound, normalized to approximately -3 dBFS.

`capture.ogg` and `capture.mp3` are original procedural recordings generated for
MistChess from two layered filtered-noise and low-frequency wood-impact
transients. They contain the same 285 ms source sound, normalized to
approximately -2 dBFS.

`mistchess-tone.ogg` and `mistchess-tone.mp3` remain the original procedural
FFmpeg sine tone used by non-move interface events.

No asset contains a third-party recording. All six files were created for this
project and are distributed under the same license as MistChess. Ogg Vorbis is
the preferred browser encoding; MP3 is the compatibility fallback.
